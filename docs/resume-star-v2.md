# 简历 STAR 草稿：仅写已验证的个人工程项目

在能独立讲解并复现这些机制后，可根据实际个人投入调整表述：

**项目：研发 Issue 审阅与协作 Agent（个人项目）**

- S/T：针对 Issue 信息收集、人工审阅与外部写入容易脱节的问题，设计按仓库规则调查并生成可审阅草稿的助手。
- A：使用 Python、FastAPI、LangGraph、MCP、SQLite 和 DeepSeek；实现签名事件接入、持久任务队列、可编辑方案版本、绑定输入快照的人工批准，以及远端写入的读回核验与不确定结果处理。
- R：本地 50 项自动化测试、40 例离线控制场景通过；两个公开工单快照完成规则、单次模型和 Agent 三组回放，保留调用量及耗时记录。

不能写：已服务企业客户、准确率提升、节省 X% 工时、分布式高并发、完整沙箱隔离，或“独立从零完成所有代码”，除非今后有对应事实。AI 辅助开发不妨碍展示项目，但面试中需要能解释和修改自己提交的代码。

当前数字是测试与联调证据，不是业务收益。后续用独立标注与真实试用数据替换项目结果中的主要指标，具体方案见 pilot-evaluation.md。
